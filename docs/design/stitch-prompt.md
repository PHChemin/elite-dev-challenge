Product: PHCTickets. Brazilian cinema ticketing web app. Portuguese UI. Wordmark “PHCTickets”.

Colors (use exactly):
- Black / text / occupied seats: #161A1D
- Primary / brand / selected seat / main buttons: #660708
- Support / alerts / already-used / scan error: #BA181B
- Page background / surfaces: #F5F3F4
Gate “Válido” must not use the same red as errors. High contrast on the light background.

Clean, direct UI. Reference: Sympla (sympla.com.br) — event cards with date, venue, price; short checkout; little decoration. Not a SaaS dashboard. Not a generic AI landing page. Not a dark cyber theater poster. Light page (#F5F3F4), not a black theme.

Screens to generate (desktop + mobile, same visual system):

1. Login. Email and password. No social login wall. PHCTickets wordmark.
2. Published sessions list. Poster, title, date, venue, price.
3. Session detail. Poster, short synopsis, date, venue, price, CTA “Escolher assentos”.
4. Organizer: create session. Search movie (TMDb), date, venue, price, max tickets per order (default 6). Publish.
5. Seat map. Rows and seats. States: free, selected (#660708), held by me, taken (#161A1D). Short legend. Timer after going to checkout (10:00).
6. Simulated payment. Approve / decline. Order summary with seats.
7. My tickets list.
8. Ticket view. Large QR, session info, seat, copy share link.
9. Gate: pick which session this door is covering. Big session name after choice.
10. Gate: camera + manual code. Session name always on screen. Huge status: Válido / Inválido / Já utilizado / Evento errado.

Constraints:
- One primary action per screen.
- No stock “happy crowd in a theater” illustrations.
- No 12-metric admin home.
- Seat map readable, not 3D cinema.
- Gate screens for a staff phone in a queue: large tap targets, high contrast status.

Style: contemporary Brazilian product, editorial but calm, Sympla-like density on list/detail, more utilitarian on gate and seat map.
